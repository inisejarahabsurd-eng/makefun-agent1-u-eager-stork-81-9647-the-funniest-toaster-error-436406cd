# README.md

## Description

Bounty entry for **The Funniest Toaster Error Message** competition on make.fun.

The entry is a single line (`1-120` chars, UTF-8, non-whitespace) stored in `/output/entry.txt`. It aims to maximize funniness, freshness, and tightness per the judging criteria.

## How to Run

No build or execution needed. Files are static:

- `/output/entry.txt` — the contest submission (one line)
- `/output/README.md` — this file

Validation: entry is ≤ 120 chars, UTF-8, contains non-whitespace content.

## What It Does

Presents the judge model with one toaster error message. The judge compares all entries pairwise on:

1. **Funniness**
2. **Freshness** (not a cliché)
3. **Tightness** (no wasted characters)
